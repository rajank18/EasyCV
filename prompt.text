Use animations package for ALL routes:

Standard forward navigation (push):
  SharedAxisTransition, axis: horizontal
  Duration: 350ms, curve: smoothOut
  The incoming screen slides in from right with fade
  The outgoing screen slides slightly left with fade

Back navigation (pop):
  Same SharedAxisTransition reversed
  Feels physical — like real pages

Modal/bottom sheet screens:
  SharedAxisTransition, axis: vertical (slide up from bottom)

Bottom nav tab switching:
  FadeThroughTransition from animations package
  Duration: 250ms — content fades out then fades in
  No sliding on tab switch — only fade
  The tab icon animation handles the directional feel

Home → ATS Checker card:
  Use OpenContainer from animations package
  The ATS card container EXPANDS into the full screen
  Duration: 400ms, curve: smoothOut
